# Undo Send

Wait a few seconds after Send, so you can take the message back. Undo Send holds a message after you click Send. A small window counts down. Choose **Undo send** before it reaches zero and the message stays in the compose window.

The wait is between 5 and 30 seconds. The default is 10. The delay is on as soon as the add-on is installed. This add-on needs Thunderbird 128 or newer.

## Install from a file

1. Download [`releases/undo-send-1.0.0.xpi`](releases/undo-send-1.0.0.xpi).
2. In Thunderbird, open the menu and choose **Add-ons and Themes**.
3. Click the gear icon and choose **Install Add-on From File…**.
4. Select the downloaded `.xpi` file.
5. When Thunderbird asks for access, choose **Add**.

## Install from add-on search

1. In Thunderbird, open the menu and choose **Add-ons and Themes**.
2. In the search field, type `Undo Send` and press Enter.
3. Open the result for this add-on, by Ilya Devin, and choose **Add to Thunderbird**.
4. When Thunderbird asks for access, choose **Add**.
